## 已定实施选择

- 默认 TCP，可选 UDP。无自动重连、可靠 UDP、统一主动缺口通知、复杂 TUI、PID 附着。
- 按记录数及字节数双限额滚动缓冲；发布成功不代表 Output 处理或持久化。
- 旧源码与旧协议测试通过 Git 历史保留。旧版本验收不当作本版验证；本版以新契约测试为准。
- 原工作目录的既有改动与本地资料保持原样，实施位于独立工作区。

## 执行证据

本机macOS完整协调器 `full-local-3` 全部9阶段通过：64个Rust测试；13个协议、8个CLI（Core崩溃含TCP/UDP子场景）、4个失败生命周期、11类输入（tmux无skip）、12个输出，共48项进程验收。格式与Clippy零警告，workspace构建通过。

额外审查并回归：Core崩溃收尾、自有source/后代退出；退出7导致stop非零、restart不再拉起；新进程未注册不能沿用旧终态；运行时反馈环、事件订阅占用、UDP1030次管理短连接，以及同端口重新注册和旧请求队列已满的两项确定性回归。转换插件新增关闭重排/缺少来源序号时的状态上限、真实到期调度验收。Windows SQLite 测试读取后显式关闭连接，避免测试自己占用归档文件。

文档验收：公开站 21 页、704 个链接目标无错误，20 个公开输入文件通过隔离审计；本地站 177 页、11267 个链接目标无错误。浏览器实测模块导航与搜索，控制台无错误。`git archive` 导出的提交源码通过 `cargo check --workspace --locked`，不依赖本地忽略文件。

本机完整日志保留于 `quality/artifacts/release-0.1.2/`（Git忽略）。公开仓库只提交可重复运行的测试与本验收摘要，不提交运行凭据、PID状态文件或本地内部文档。

最终强杀任意卡死的Unix插件时，插件的清理代码无法执行，故返回forced/失败及来源进程清理未确认，不宣称任意SIGKILL情形都能安全收尾。TCP/UDP常规Core崩溃回收已实际验证；Windows需以对应CI结果为准。
