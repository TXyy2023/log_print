## 已定实施选择

- 默认 TCP，可选 UDP。无自动重连、可靠 UDP、统一主动缺口通知、复杂 TUI、PID 附着。
- 按记录数及字节数双限额滚动缓冲；发布成功不代表 Output 处理或持久化。
- 旧源码与旧协议测试通过 Git 历史保留。旧版本验收不当作本版验证；本版以新契约测试为准。
- 原工作目录的既有改动与本地资料保持原样，实施位于独立工作区。

## 执行证据

本机macOS完整协调器 `full-local-2` 全部9阶段通过：59个Rust测试；13个协议、8个CLI（Core崩溃含TCP/UDP子场景）、4个失败生命周期、11类输入（tmux无skip）、10个输出，共46项进程验收。格式与Clippy零警告，workspace构建通过。

额外审查并回归：Core崩溃收尾、自有source/后代退出；退出7导致stop非零、restart不再拉起；新进程未注册不能沿用旧终态；运行时反馈环、事件订阅占用、UDP1030次管理短连接。

本机完整日志保留于 `quality/artifacts/release-0.1.2/`（Git忽略）。公开仓库只提交可重复运行的测试与本验收摘要，不提交运行凭据、PID状态文件或本地内部文档。

最终强杀任意卡死的Unix插件时，插件的清理代码无法执行，故返回forced/失败及来源进程清理未确认，不宣称任意SIGKILL情形都能安全收尾。TCP/UDP常规Core崩溃回收已实际验证；Windows需以对应CI结果为准。

为本机真实tmux验收安装了tmux与jemalloc。Homebrew自动cleanup曾清理旧Cellar版本/缓存，当前链接版本已核验保留，详见本地 `tmux-environment.md`；后续安装禁止自动cleanup。
