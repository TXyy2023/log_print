# WebUI：日志阅读工具

设计修订：2026-10-13。适用于当前唯一的 WebUI 首页。

## 用户与工作流

面向在本机调试程序、导入设备日志的开发者。高频流程是选择来源、跟随输出、暂停定位、筛选命中、检查上下文、保存原始证据。来源、当前查看范围、显示状态始终可见；详细标识和文件路径按需展开。

参考用户提供的 `mainstream-log-serial-tools-2026-10-02.md`：

- [klogg](https://klogg.filimonov.dev/)：命中与原始上下文分开；筛选后仍能读取前后日志。
- [LogExpert](https://github.com/LogExperts/LogExpert)：持续跟随、搜索高亮与独立筛选。
- [lnav](https://lnav.org/features)：来源与查询范围明确；显示不替代原始证据。

这里只采用与当前日志闭环相关的设计。高级解析、SQL、图表、书签、串口发送不作为本次已实现能力。

## 设计系统

1. **方向**：仪器式日志阅读界面。石墨色应用栏提供稳定边界；浅灰来源栏和白色日志面形成层级，细边框分区。没有营销大标题、装饰图、统计卡片或画布。旧工作台前端、备用入口及依赖移除。
2. **字体**：系统无衬线用于操作，系统等宽字体用于日志与标识，无远程字体。标题 14px，操作 12–13px，日志 12px，辅助信息 10–11px；日志行高 26px。
3. **颜色**：中性色承载正文；绿色只用于选中、主要操作和有效连接；琥珀色表示暂停、保存进行中和缺口；红色表示失败。搜索命中使用浅琥珀底色。浅色为默认，可切换深色，主题保存在本机浏览器。
4. **间距**：4/8/12/16/24px；桌面来源栏 212px，宽屏 228px；详情栏 340px，宽屏 380px。主要按钮 30px 高、4px 圆角。日志区域尽量占据有效高度。
5. **组件**：扁平工具栏、来源行、虚拟日志表格、辅助详情栏、保存记录对话框。原文与元信息使用不同排版，不机械套卡片。统一线性 SVG 图标。
6. **交互**：可见 hover/focus/selected/disabled；连接中断、读取中、导入中、无匹配、无来源、输出失败各有真实状态。Ctrl/Cmd F 查找，Enter/Shift Enter 定位匹配，日志表内方向键/PageUp/PageDown/Home/End 导航，Space 暂停，Esc 关闭浮层。保存先选择明确起点，停止提交后才提供下载。
7. **响应式**：900px 以下来源栏为带焦点约束的抽屉；1200px 以下详情变为侧边浮层；600px 以下搜索控件分两行、保存记录从底部展开。长日志在表格内部横向滚动，详情可以换行；页面本身不横向溢出。

## 工程边界

`useLogSession.ts` 管理连接、缓存读取、固定历史查询、上传和保存；视图组件不直接调用 API。`LogTable.vue` 只渲染可见范围，`SourceList.vue`、`RecordInspector.vue`、`RecordingDrawer.vue` 独立处理各自呈现。运行时依赖仅 Vue；Rust 共享查询引擎继续供 CLI/TUI 使用。

高亮按字面匹配，渲染使用文本插值。单行最多创建 256 个高亮片段，保留剩余原文，防止极端长行生成失控 DOM。仅高亮不触发历史重新扫描。迟到查询结果用版本标记丢弃，关闭/切换时取消任务。

## 验收与已知限制

浏览器验收必须覆盖 1440×900、1280×800、390×844：真实数据、空状态、筛选、键盘导航、上下文、两种保存、下载、文件导入、主题、抽屉与长内容。截图由真实 Rust 服务生成，fixture 明确标记为测试日志。

边界：上传仍限 64 MiB；实时窗口最多 2,000 行，历史分页最多 200 行。高亮导航只针对当前显示窗口/历史页；固定历史结果不自动更新。UTF-8 是展示方式，未提供其他编码选择。保存文件在磁盘保留，但运行中的来源与保存记录列表不会在 supervisor 重启后自动重建。跨平台、触摸真机和屏幕阅读器实机验收需单独执行。

## 本次设计复核（2026-10-13）

实际复核了 1440×900、1280×800、390×844 的浅/深色、实时、筛选上下文、保存弹层、空页面与故障截图。第一轮发现固定列阴影遮挡首字符、手机原生 dialog 默认最大宽度造成底部留空、详情展开后匹配位置移出横向视口；修正后重新截图和回归。深色截图等待颜色切换完成，避免把过渡帧误判成最终配色。
